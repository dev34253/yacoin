## Goal

Have reproducible mainnet and low-difficulty builds with optional coverage and sanitizer instrumentation.

## Steps

1. Script (e.g. contrib/testing/build.sh) running inside the Ubuntu 24.04 / GCC 11 image from P0-57 (`dev34253/yacoin-build:ubuntu.24.04-gcc11-1`): depends with NO_QT=1 (Qt deferred, P0-00 decision 5), then configure and build.
2. Options: --config mainnet|lowdiff, --coverage (sets both CFLAGS and CXXFLAGS so scrypt-jane C code is instrumented), --sanitizers (filled in by P0-29).
3. Build out-of-tree so the checkout stays clean.
4. Measure test_bitcoin runtime in both configurations (TestChain100Setup brute-forces blocks; mainnet powLimit may be slow) and record it.
5. Document usage, including the HTTPS proxy/CA variables needed in restricted environments, in contrib/testing/README.md.

## Acceptance criteria

- [x] Both configurations build from a clean checkout with one command each.
- [x] The source tree has no untracked or modified files after a build.
- [x] Unit-test runtime per configuration recorded in Log, with a recommendation for which configuration(s) CI runs unit tests in.

## Detailed description

(Written after implementation – P0-01 predates the `implement-task` skill; it
records what was built and tested.)

- **Scope:** `contrib/testing/build.sh` (driver), `contrib/testing/sync_tree.py`
  (checkout mirror), `contrib/testing/README.md`, and an opt-in
  `BUILD_GIT_COMMIT` fallback in `share/genbuild.sh`. No C++ or consensus
  changes.
- **Behaviour:** one command per configuration
  (`--config mainnet|lowdiff`, optional `--coverage`, `--sanitizers LIST`,
  `--unit`, `--functional`) builds `depends` (NO_QT=1) and YaCoin inside the
  pinned P0-57 image, out of tree in a work dir (default
  `~/.cache/yacoin-build`), and runs the requested tests.
- **Edge cases handled and how they were tested:**

| Edge case | Handling | Test |
|---|---|---|
| Fresh machine, empty cache | depends downloaded and built | fresh run 11.5 min, mainnet 239/239 |
| Checkout must stay clean | build from a mirror outside the checkout | `git status` after runs shows only own edits |
| Tracked files regenerated by autogen.sh (aclocal.m4, build-aux/*) | manifest-based sync leaves them alone | scratch repo test; real incremental runs |
| Automatic `config.status --recheck` loses `CONFIG_SITE` | also `--prefix=<depends prefix>` | reproduced failure, then fixed run |
| Changed configure arguments | `.configure-args` triggers reconfigure | mainnet re-run after `--prefix` change |
| Deleted (unstaged), renamed, untracked, ignored files; file↔dir swaps | sync removes/creates accordingly | scratch repo tests |
| Edit during a running build | copies get the current mtime | scratch test (mtime 2026 vs checkout 2001) |
| Work dir inside / containing the checkout, `$HOME`, `/`, symlinks | rejected before anything is created | 5 guard tests |
| Concurrent runs | `flock` on `WORK_DIR/.lock` (held across `exec docker`) | second run rejected while first ran |
| Ctrl-C | `docker run --init` | – (by design) |
| Missing option values, bad config, `--functional` without lowdiff | clear errors | guard tests |
| Proxy / CA in restricted networks | passed into the container | cloud-session runs |
| Version string without `.git` in the copy | `BUILD_GIT_COMMIT` (with `-dirty`) | `yacoind -version` shows commit |
| Failed functional tests | datadirs kept in `<builddir>/functional-tmp` | – |
